One-line: the brand's action control — use \`primary\` once per screen region, \`secondary\` for the paired alternative, \`ghost\` for nav-level actions like "Sign in".

\`\`\`jsx
<Button variant="primary" size="lg">Request a demo</Button>
<Button variant="ghost" size="sm">Sign in</Button>
\`\`\`

Variants: primary (indigo), secondary (white + hairline), ghost, inverse (on indigo/ink), onDark (outline on ink), warm (pill, clay — page-two only). Sizes sm/md/lg map to 34/42/50px. \`block\` for mobile stacking.
